# Agent Skills Directory

This directory stores reusable Python "Skills" (functions) generated by the Graph-RLM Agent.
When the agent codifies a successful tool usage pattern or learns a new capability, it writes the Python code here.

These skills are automatically loaded by the `SkillsManager` and injected into the agent's context.

## Structure

Each skill is a standalone Python file (e.g., `web_search.py`).
Metadata is managed via `skills_registry.json` (if applicable) or by parsing the file docstrings/decorators.
