## System Design

### Principle
```
mcp_tools/<MODULE_NAME>.py  →  MCPServerNamespace(mod_name, mod_name)
                            →  Accessed as mcp.<MODULE_NAME>.<FUNCTION>()
```

### Data Flow

```
User Code
  ↓
mcp.brave_search.brave_web_search(...)
  ↓
LazyMCPNamespace.__getattr__("brave_search")
  ↓
_aliases["brave_search"] = MCPServerNamespace("brave_search", "brave_search")
  ↓
MCPServerNamespace.__getattr__("brave_web_search")
  ↓
_ensure_loaded() → import_module("graph_rlm.backend.mcp_tools.brave_search")
  ↓
Find brave_web_search() function in the module
  ↓
Wrap with async/logging, return callable
  ↓
Execute and return result
```

## Architecture Components

### 1. MCPServerNamespace (agent.py, lines 53-125)

```python
class MCPServerNamespace:
    """Lazy-loaded namespace for a single MCP server."""

    def __init__(self, mod_name: str, alias: str, rlm_interface):
        self._mod_name = mod_name        # e.g., "brave_search"
        self._alias = alias              # e.g., "brave_search" (now == mod_name)
        self._module = None
        self._tools = {}                 # Cache of loaded tools
        self._docs = {}                  # Tool documentation

    def _ensure_loaded(self):
        # Import module only on first access
        self._module = import_module(f"graph_rlm.backend.mcp_tools.{self._mod_name}")

        # Discover all callable attributes
        for attr in dir(self._module):
            if callable(getattr(self._module, attr)):
                # Wrap with async support and logging
                self._tools[attr] = make_wrapper(...)

    def __getattr__(self, name):
        # When user accesses mcp.brave_search.brave_web_search
        self._ensure_loaded()
        if name in self._tools:
            return self._tools[name]
        raise AttributeError(f"MCP Server '{self._alias}' has no tool '{name}'")
```

**Key Fix**: Now `self._alias == self._mod_name` always, so error messages are accurate.

### 2. LazyMCPNamespace (agent.py, lines 127-183)

```python
class LazyMCPNamespace:
    """Lazy-loaded root namespace for all MCP servers."""

    def _scan(self):
        # On first access to mcp, enumerate all modules
        for _, mod_name, _ in pkgutil.iter_modules(mcp_tools_pkg.__path__):
            # Create namespace for each module using its actual name
            server = MCPServerNamespace(mod_name, mod_name, self._rlm_interface)
            self._aliases[mod_name] = server
            logger.info(f"Registered MCP server: {mod_name}")

    def __getattr__(self, name):
        # When user accesses mcp.brave_search
        self._scan()
        if name in self._aliases:
            return self._aliases[name]
        raise AttributeError(f"No MCP server found with name '{name}'")
```

**Key Fix**: Removed all alias generation. Single registration per module.

## Generated Wrapper Functions

### Example: brave_search.py

```python
"""Auto-generated wrapper for brave-search MCP server."""

def brave_web_search(query: str, count: float | None = None, offset: float | None = None) -> Any:
    """Performs a web search using the Brave Search API."""

    async def _async_call():
        return await call_mcp_tool(
            server_name="brave-search",
            tool_name="brave_web_search",
            arguments={...}
        )

    try:
        loop = asyncio.get_running_loop()
        if loop.is_running():
            return _async_call()  # Return coroutine for async contexts
    except RuntimeError:
        pass

    # Fallback to sync execution if not in async context
```

### Key Points

1. **Async-Safe**: Returns awaitable in async context, handles sync fallback
2. **Generated**: Auto-generated by `generator.py` from MCP server introspection
3. **Transparent**: User doesn't need to know about `call_mcp_tool()` implementation

## Common Patterns

### Using MCP Tools in REPL Code

```python
# Simple search
result = await mcp.brave_search.brave_web_search(query="topic")

# Chain operations
url = result[0]['url']
content = await mcp.mcp_server_firecrawl.firecrawl_scrape(url=url)

# Multiple servers
papers = await mcp.arxiv_mcp_server.arxiv_query(query="neural networks")
containers = await mcp.docker_mcp.docker_ps()
```

### Writing Skills Using MCP

```python
async def research_skill(topic: str):
    """Skill that uses multiple MCP servers."""

    # Search web
    results = await mcp.brave_search.brave_web_search(query=topic)

    # Scrape first result
    if results:
        url = results[0]['url']
        content = await mcp.mcp_server_firecrawl.firecrawl_scrape(
            url=url,
            formats=["markdown"]
        )
        return content

    return "No results found"
```

## Error Handling

### Tool Not Found

```python
# Error: AttributeError: No MCP server found with name or alias 'brave'
# Cause: 'brave' is not a registered module (alias was removed)
# Fix: Use 'brave_search' instead
```

### Function Not Found

```python
# Error: MCP Server 'brave_search' has no tool 'search'
# Cause: Function 'search' doesn't exist in the module
# Fix: Check available tools with dir(mcp.brave_search)
```

### Not Awaiting Async Call

```python
# Problem: result = mcp.brave_search.brave_web_search(query="test")
#          print(result)  # Output: <coroutine object...>
# Fix: result = await mcp.brave_search.brave_web_search(query="test")
```

## Performance Considerations

1. **Lazy Loading**: Modules only imported on first tool access
2. **Caching**: Tools cached in `_tools` dict after first load
3. **Async**: All tools properly async to avoid blocking
4. **Recording**: Tool use logged for audit/debugging
