  </files>
  <behavior>
    When circuit breaker is OPEN and MCP call is attempted:
    - CircuitOpenError is raised immediately
    - Error contains circuit_name="mcp_server"
    - No actual MCP connection attempt is made

    When circuit breaker is CLOSED and MCP call succeeds:
    - Call executes normally
    - Circuit remains CLOSED
    - Failure count resets on success

    When failure threshold is exceeded:
    - Circuit transitions from CLOSED to OPEN
    - Subsequent calls raise CircuitOpenError
    - Circuit transitions to HALF_OPEN after timeout
  </behavior>
  <implementation>
    Create McpCircuitBreaker wrapper around core CircuitBreaker
    Create safe_mcp_call function that wraps MCP client calls
    Export for test imports
  </implementation>
</feature>
